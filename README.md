# Customer Churn Prediction

Predicting which customers are likely to churn with classical machine-learning models.

## Contents

| File | What it is |
|------|------------|
| `notebooks/churn_prediction.ipynb` | IMPORTING LIBRARIES |

## Getting started

```bash
git clone https://github.com/<your-username>/customer-churn-prediction.git
cd customer-churn-prediction
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install jupyterlab
jupyter lab   # then open a notebook in notebooks/
```

## Notes

- The dataset is not included; point the notebook at your own copy.
